Current Recap

Connect the extension to your Current Recap server. In Current Recap go to Connections → Create token, create an access token, then paste the server address and token here.

What this extension does
  • Runs only on Facebook, Instagram, Threads and Meta Quest pages.
  • Sends the link and page title of a post, reel, video or story you stay on, plus time spent, to your own Current Recap server. Nothing goes anywhere else.
  • Never runs on Messenger, WhatsApp or Meta AI, and ignores feeds, profiles and search pages.
  • Use the toolbar icon to pause it at any time.
